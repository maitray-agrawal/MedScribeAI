# MedScribeAI — Zero-Cost Deployment Guide

MedScribeAI supports two independent, zero-cost deployment targets:
1. **Public Web Demonstration:** Hosted on the Cloudflare Pages Free Tier (`*.pages.dev`).
2. **Sovereign Desktop Application:** Packaged via Tauri v2 and distributed via GitHub Releases.

---

> **CRITICAL ARCHITECTURAL DISTINCTION**  
> The **Web Demo** is a lightweight, browser-based demonstration designed for quick evaluator previews and mobile walkthroughs using pre-loaded synthetic scenarios. It is **not** the authoritative offline clinical runtime.  
> The **Windows Desktop Application** is the primary demonstration of the offline-first, sovereign architecture featuring the bundled Python 3.11 sidecar, local SQLite database, and ONNX acoustic model.

---

## Target A: Public Web Demonstration (Cloudflare Pages)

The web demo is deployed as static client-side assets directly from the repository using the Cloudflare Pages Free Tier.

### Zero-Cost Deployment Attributes
- **Cost:** ₹0 / month (100% Free Tier).
- **Custom Domain Required:** No. Deploys to free subdomain: `https://<project-name>.pages.dev`.
- **Database Required:** No. Browser localStorage is used for temporary demo session state.
- **Backend API Required:** No. The web demo features pre-loaded synthetic clinical encounters.

### Cloudflare Pages Git Integration Setup
1. Log in to the [Cloudflare Dashboard](https://dash.cloudflare.com/) (Free account).
2. Navigate to **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git**.
3. Select repository: `maitray-agrawal/MedScribeAI`.
4. Configure the build settings:
   - **Project Name:** `medscribe-ai` (or desired name)
   - **Production Branch:** `main`
   - **Framework Preset:** `Vite` (or None)
   - **Build Command:** `npm run build`
   - **Build Output Directory:** `dist`
   - **Root Directory:** `/` (leave blank)
5. Environment Variables:
   - `NODE_VERSION`: `20`
6. Click **Save and Deploy**.
7. Cloudflare Pages automatically builds the static frontend and provisions the live URL:
   `https://medscribe-ai.pages.dev`

### Testing the Web Build Locally
Before deploying, verify the exact static output generated by Vite:
```powershell
npm run build
# Output verified in dist/
# dist/index.html
# dist/assets/index-*.css
# dist/assets/index-*.js
```

## Target B: Sovereign Desktop Application (Tauri + GitHub Releases)

The desktop application is distributed as a single, self-contained Windows x64 NSIS installer via GitHub Releases.

### Zero-Cost Distribution Attributes
- **Hosting Cost:** ₹0 (Public GitHub Releases).
- **CI Build Cost:** ₹0 (Standard GitHub Actions runners on public repository).
- **Code Signing Cost:** ₹0 (Unsigned open-source release with declared SmartScreen guidance).

### Building the Windows Installer Locally
To build the complete Windows release package locally on Windows 10/11:
```powershell
# 1. Install dependencies
npm ci
pip install -r backend/requirements.txt pyinstaller

# 2. Build Python backend sidecar binary
powershell -ExecutionPolicy Bypass -File scripts/build_backend_sidecar.ps1

# 3. Build Tauri NSIS installer
npx tauri build --bundles nsis
```
The output installer is generated at:
`src-tauri/target/release/bundle/nsis/MedScribeAI_1.0.0_x64-setup.exe` (~202.7 MB).

### Triggering Automated Release via GitHub Actions
To publish a new official release:
1. Push a version tag:
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
2. Or trigger manually via GitHub Actions UI:
   - Navigate to `https://github.com/maitray-agrawal/MedScribeAI/actions`.
   - Select the **Release** workflow.
   - Click **Run workflow** on branch `main`.
3. The workflow executes all tests, builds the Tauri NSIS package, generates `SHA256SUMS.txt`, and publishes the release assets to GitHub Releases.
